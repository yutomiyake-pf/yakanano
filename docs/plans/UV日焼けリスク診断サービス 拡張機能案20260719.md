# UV日焼けリスク診断サービス 拡張機能案

---

## PV・リピーター増加につながる機能

毎日来てもらうための仕掛けが最重要です。

| 機能 | 概要 | 効果 |
|---|---|---|
| **今日の全国UV速報** | 都道府県別のUVランキングをトップページに表示（「今日一番紫外線が強い県は〇〇」） | SEOで「今日 紫外線 強い」などのキーワードを拾える。毎日更新されるのでリピーターが増える |
| **UV通知機能（PWA）** | 「今日のUVが高い時間帯になったらプッシュ通知」をPWAで実装 | 毎日アクセスしなくても能動的に呼び戻せる |
| **週間UV予報** | 3日間から7日間に拡張。「今週末の海水浴は何SPFが必要？」 | 週末の計画を立てるユーザーが金曜に検索してくる |
| **UV日記・記録機能** | 「今日の日焼け具合」を記録して累積で見られる（localStorage） | ゲーミフィケーション的な継続利用を促す |

## アフィリエイト収益を直接上げる機能

| 機能 | 概要 | 収益への貢献 |
|---|---|---|
| **SPF別日焼け止め比較** | 「あなたに必要なSPF50+の日焼け止めはこれ」と商品をレコメンド（Amazonアソシエイト） | 購買意欲が最も高いタイミングで商品を見せられる |
| **肌タイプ別スキンケア診断** | 肌タイプを入力すると「あなたにおすすめの日焼け後ケア商品」を提案 | コスメ・美容系アフィリエイトの単価が高い |
| **アウトドア別UVアドバイス** | 「海水浴」「ゴルフ」「登山」「ランニング」など用途を選ぶとSPFや装備をレコメンド | 用途に合わせた商品リンクを自然に配置できる |
| **子ども向けUV診断** | 子どもの肌は大人より敏感という切り口で、子ども用日焼け止めをレコメンド | ベビー・キッズ用品は単価が高く、親世代は購買力が高い |

## SEOを強化する機能

| 機能 | 概要 | 狙えるキーワード |
|---|---|---|
| **地域別UVページ** | 「東京のUVインデックス」「沖縄のUVインデックス」など都市別の静的ページを生成 | 「〇〇 紫外線 今日」のロングテールキーワードを大量に獲得 |
| **季節・月別UV解説コンテンツ** | 「7月の紫外線はなぜ強い？」「梅雨でも紫外線は強い？」などのコラム | 情報系キーワードで検索流入を増やす |
| **UV豆知識コーナー** | 「曇りの日でも紫外線は80%届く」などのファクトを毎日1つ表示 | SNSでシェアされやすいコンテンツになる |
| **肌タイプ診断コンテンツ** | 「自分の肌タイプ（Fitzpatrick Scale）を調べる」診断ページ | 「肌タイプ 診断」は検索ボリュームが高い |

## UXを向上させる機能

| 機能 | 概要 | 効果 |
|---|---|---|
| **外出時間入力 → 日焼け量計算** | 「10時〜15時に外にいる予定」を入力すると、その時間帯の累積UV量と日焼けリスクを計算 | より実用的で「使えるツール」感が増す |
| **リアルタイム時刻表示** | 「現在（14:00）のUVは〇〇です。あと〇分で日焼けします」とリアルタイム表示 | 今この瞬間のリスクが伝わり、行動変容につながる |
| **天気との連動表示** | 晴れ/曇り/雨のアイコンとUVを並べて表示。「曇りでもUV高い」を視覚的に伝える | 「曇りだから大丈夫」という誤解を解消できる |
| **日焼け止めの塗り直しタイマー** | 「2時間後に塗り直しリマインダー」をPWAで設定できる | 実用性が高くリピーターになりやすい |
| **シェア機能の強化** | 「今日の渋谷区のUVは〇〇（高）。白肌の私は14分で日焼けします」という画像を自動生成してXにシェア | バイラル流入が増える |

## 優先度まとめ

### すぐやるべき（実装コスト低・効果大）

1. **外出時間入力 → 累積UV計算** — 実用性が一気に上がる
2. **地域別UVページの静的生成** — SEOで長期的な流入を作る
3. **リアルタイム時刻表示** — 「今この瞬間」のリスクを伝える
4. **SPF別日焼け止めレコメンド** — アフィリエイト収益に直結

### 次のフェーズ（実装コスト中）

5. **全国UV速報ページ** — 毎日来るユーザーを作る
6. **日焼け止め塗り直しタイマー（PWA）** — リテンション向上
7. **シェア画像の自動生成** — バイラル流入を狙う
