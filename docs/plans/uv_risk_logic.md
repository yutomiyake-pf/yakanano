# UV日焼けリスク算定ロジックと科学的根拠

本ドキュメントは、yakanai が表示する 3 つの値
— **リスク度合い**（リスク低〜極端）、**日焼けするまでの目安時間**、**推奨される対策** —
の算定ロジックを実装レベルで説明し、それぞれが科学的・生物学的にどこまで根拠を持つか、
どこからが簡略化・近似かを明示することを目的とする。

実装はすべて [`lib/uv.ts`](../../lib/uv.ts) に集約されている。

> **重要（免責）**: 本サービスの出力は一般向けの目安であり、医療的助言ではない。
> 実際の日焼け・皮膚障害のリスクは個人差と環境要因に大きく左右される。詳細は [§5 限界と注意点](#5-限界と注意点) を参照。

---

## 0. 前提となる指標

### UVインデックス（UVI）

Open-Meteo から取得する `uv_index` は、WHO/WMO/UNEP/ICNIRP が定めた
**Global Solar UV Index（世界共通紫外線指数）** である。これは、地表に到達する紫外線
放射照度を **CIE 紅斑作用スペクトル（erythemal action spectrum, McKinlay & Diffey 1987）**
で重み付けし、皮膚に紅斑（日焼けによる赤み）を生じさせる能力に換算した値に比例する。

- 定義: `UVI = 40 × (紅斑加重放射照度 [W/m²])`
- UVI は「その光がどれだけ人の皮膚を焼くか」を直接表す量であり、単なる明るさや気温とは独立。

→ **UVI 自体は国際標準に基づく科学的な量**であり、本サービスの全計算の土台となる。

## 1. リスク度合いの判定

### ロジック（`getRiskLevel`）

日最大 UVI（または各時刻の UVI）を以下の閾値で 5 段階に分類する。

| UVI | リスク | 色 | 実装キー |
|---|---|---|---|
| 0〜2 | 低 | 緑 `#22c55e` | `low` |
| 3〜5 | 中 | 黄 `#eab308` | `moderate` |
| 6〜7 | 高 | 橙 `#f97316` | `high` |
| 8〜10 | 非常に高い | 赤 `#ef4444` | `veryHigh` |
| 11+ | 極端 | 紫 `#a855f7` | `extreme` |

```ts
if (uvIndex >= 11) return extreme;
if (uvIndex >= 8)  return veryHigh;
if (uvIndex >= 6)  return high;
if (uvIndex >= 3)  return moderate;
return low;
```

### 科学的根拠: ★★★（強い）

この 5 段階の区分（Low / Moderate / High / Very high / Extreme）と、それぞれに対応する
**緑・黄・橙・赤・紫のカラーコードは、WHO が公表する UV Index の公式な曝露カテゴリーと完全に一致する**
（WHO, *Global Solar UV Index: A Practical Guide*, 2002）。

- これは各国の気象機関（気象庁、米国 EPA、豪州 ARPANSA など）が採用する国際標準の分類であり、
  公衆衛生上のエビデンスに基づいて設定されている。
- 閾値は恣意的な独自基準ではなく、標準の踏襲である点が強み。

## 2. 日焼けするまでの目安時間

### ロジック（`calcSunburnTime`）

```ts
sunburnTime[分] = BASE_MINUTES[skinType] / uvIndex × spf
```

- `BASE_MINUTES` = **UVI=1 のときに、その肌タイプが日焼け（紅斑）を起こすまでの分数**

  | Fitzpatrick 肌タイプ | 基準時間(分) @UVI=1 |
  |---|---|
  | I  超白肌 | 67 |
  | II 白肌 | 100 |
  | III 普通（標準的な日本人） | 200 |
  | IV やや濃い | 300 |
  | V  濃い | 400 |
  | VI 非常に濃い | 500 |

- `uvIndex` で割る: UVI は紅斑加重放射照度に比例するため、**強度が 2 倍なら焼けるまでの時間は 1/2**
  という逆比例関係を表す。
- `spf` を掛ける: 日焼け止めの SPF は「保護により紅斑到達を何倍遅らせるか」の指標なので、
  時間を線形に延長する。
- `uvIndex <= 0`（夜間など）は `null` を返し「日焼けしません」と表示。

計算例: 標準肌（III, base=200）・UVI=8・SPF30 → `200 / 8 × 30 = 750 分（12.5 時間）`
（＝この条件では日中に焼き切るほどの曝露にはなりにくい、と読める）。

### 科学的根拠: ★★（中程度 — 骨格は妥当、係数は近似）

**根拠のある部分（理論的背景）:**

1. **MED（最小紅斑量, Minimal Erythemal Dose）**
   皮膚に「かろうじて視認できる紅斑」を生じる最小の紫外線量を MED と呼ぶ。MED は皮膚科学で
   確立した概念で、肌タイプ（Fitzpatrick I〜VI）が濃いほど MED は大きい（焼けにくい）。
   → `BASE_MINUTES` が肌タイプとともに単調増加するのは、この MED の序列に対応する。

2. **時間 = 線量 / 放射照度**
   紅斑は概ね「累積線量（dose）」で決まる（相反則が近似的に成立する範囲で）。
   `到達時間 = MED / 紅斑加重放射照度`。UVI は放射照度に比例するので `時間 ∝ 1/UVI` は物理的に妥当。

3. **SPF の定義**
   SPF は `SPF = MED(日焼け止めあり) / MED(なし)` と定義される（ISO 24444 等の in-vivo 試験）。
   よって理論上は保護時間が SPF 倍になる、というモデルは定義に忠実。

**近似・簡略化している部分:**

- `BASE_MINUTES`（67〜500 分）の具体値は、一般的な「肌タイプ別 日焼け時間の目安表」に基づく
  代表値であり、単一の査読論文が定めた定数ではない。実際の MED には個人差・測定幅が大きい。
- **Fitzpatrick 分類の自己申告は主観的**で、同じ「タイプ III」でも MED はばらつく。
- 相反則（Bunsen–Roscoe law）は長時間・低強度では厳密には崩れる。
- **SPF 線形倍は理想条件の値**。後述のとおり実使用では大幅に下振れする。

→ **逆比例（UVI）× 線形（SPF）というモデルの骨格は科学的に妥当**だが、
出力される「◯分」という具体値は**オーダー感を示す目安**として扱うべきで、精密な安全時間ではない。

## 3. 推奨される対策

### ロジック（`RiskLevel.recommendedSpf` / `advice`）

リスク段階ごとに固定の推奨文を返す。

| リスク | 推奨SPF | アドバイス要旨 |
|---|---|---|
| 低 | SPF15以上 | 特別な対策は不要。長時間なら日焼け止めがあると安心 |
| 中 | SPF30以上 | 帽子・サングラス。日焼け止め塗布を推奨 |
| 高 | SPF50以上 | 日焼け止め必須・日陰の活用・塗り直し |
| 非常に高い | SPF50+必須 | 11〜15時の外出を避ける・肌の露出を控える |
| 極端 | SPF50+必須 | できるだけ外出を避ける・徹底対策 |

### 科学的根拠: ★★（中程度 — 公的助言に準拠した簡略版）

- 「UVI が高いほど、日陰・衣服・帽子・サングラス・日焼け止めを強化し、正午前後（日本では概ね
  10〜14 時、UVI ピーク帯）を避ける」という方向性は、**WHO / 気象庁の UV 対策ガイダンスと整合**する。
- ただし「リスク中は SPF30、高は SPF50」といった **SPF 値の割り当ては、分かりやすさのための
  段階的な単純化**であり、閾値ごとに厳密な臨床エビデンスがあるわけではない。
- 皮膚科の一般的助言では、日常的に **SPF30 前後・PA+++ 程度を十分量・こまめに塗る**ことが、
  ラベル値の高さより重要とされる（塗布量不足の影響が大きいため）。

## 4. データフロー上の位置づけ

```
Open-Meteo (UVI, 国際標準) 
   │
   ├─ getRiskLevel(UVI)        → リスク度合い（WHO 分類：根拠★★★）
   ├─ calcSunburnTime(UVI,     → 日焼け目安時間（MED/SPF モデル：根拠★★）
   │     skinType, spf)
   └─ RiskLevel.advice         → 推奨対策（公的助言の簡略版：根拠★★）
```

- 入力の UVI は科学的に定義された量。
- リスク分類は国際標準の踏襲で最も信頼できる。
- 時間・対策は「妥当なモデル＋近似係数」で、**相対比較（今日 vs 明日、SPF あり vs なし）**には
  十分役立つが、**絶対値の精度は保証しない**。

## 5. 限界と注意点

本ロジックが**モデル化していない / できていない**主な要因:

1. **累積線量ではなく日最大 UVI で評価**
   `calcSunburnTime` は瞬間強度ベース。実際の日焼けは 1 日の累積線量で決まるため、
   UVI がやや低くても長時間曝露で焼けることはモデルに反映されない。
2. **日焼け止めの実効値はラベル SPF より低い**
   SPF は 2 mg/cm² 塗布での試験値。実使用の塗布量はその 1/4〜1/2 が典型で、汗・水・こすれ・
   塗り直し不足により実効 SPF は大きく下がる。**SPF を額面どおり掛けると保護時間を過大評価する。**
3. **環境要因を未考慮**: 標高（1000m ごとに約 +10%）、雪・砂・水面の反射、雲の増減、
   オゾン・エアロゾルの変動、地面アルベド。
4. **個人・生理要因を未考慮**: 日焼け止め以外の光防御（メラニン既往の日焼け＝タンニング）、
   加齢、光感受性を高める薬剤・化粧品、疾患（光線過敏症）。
5. **Fitzpatrick の自己申告誤差**: タイプ選択の主観性がそのまま基準時間に効く。
6. **紅斑（sunburn）以外の害は対象外**: 光老化・DNA 損傷・皮膚がんリスク・眼への影響などは
   「赤くならなければ安全」を意味しない。UVI が低くても長期曝露の累積影響はある。

### 実装上の安全側の含意

- 出力は「**焼けるまでの上限の目安**」ではなく「**理想条件での概算**」。ユーザー向け UI には
  予報・推定値である旨の注意書き（`ForecastNotice`）を表示済み。
- 迷ったら**より短い時間・より高い防御**を選ぶのが安全側。
